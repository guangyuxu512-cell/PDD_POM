任务目标：将流程编排弹窗从"每步骤一个大区块"改为紧凑的表格行形式，弹窗加大。

需要修改的文件：
- frontend/src/components/FlowEditor.vue（或对应的流程编辑弹窗组件）
- frontend/src/styles/（如果有全局样式需要调整）

具体实现：

1. 弹窗尺寸调整：
   - width: min(80vw, 900px)
   - max-height: 80vh
   - 内容区域可滚动

2. 弹窗顶部区域（保持简洁）：
   - 流程名称输入框（一行）
   - 流程描述输入框（一行）
   - 两个输入框并排显示

3. 步骤编排区域 — 改为表格行：

   删除现有的每个步骤一个大卡片布局，替换为紧凑表格：

   | 列       | 宽度    | 组件                          |
   |---------|---------|------------------------------|
   | 拖拽手柄  | 32px   | ⋮⋮ 图标（支持拖拽排序）          |
   | 序号     | 40px   | 自动编号（1, 2, 3...）         |
   | 任务     | auto   | Select 下拉框（从注册任务列表选择）|
   | 失败策略  | 160px  | Select 下拉框（终止全部/记录并跳过/继续执行/重试N次）|
   | 同步屏障  | 80px   | Checkbox                     |
   | 合并执行  | 80px   | Checkbox                     |
   | 操作     | 80px   | [×] 删除按钮                   |

   每行高度固定 40-48px，步骤之间无间距或极小间距（2-4px）。

4. 表格底部：
   - [+ 添加步骤] 按钮，点击后在表格末尾新增一行
   - 新增行自动 focus 到"任务"下拉框

5. 拖拽排序：
   - 使用 vuedraggable 或类似库
   - 拖拽时显示蓝色插入线
   - 拖拽完成后自动重新编号

6. 弹窗底部：
   - [取消] [保存流程] 按钮，靠右对齐
   - 保存前校验：至少 1 个步骤，每个步骤必须选择任务

验收方式：
- 创建一个 6 步流程，所有步骤在弹窗内一屏可见（无需滚动）
- 拖拽排序功能正常，编号自动更新
- 每个步骤的任务和失败策略下拉框可正常选择
- 同步屏障和合并执行 checkbox 可正常勾选
- 保存功能正常，数据与后端 API 格式一致
- 弹窗在 1366x768 分辨率下不溢出
